# Certificate images

Put your certificate images in this folder.

Use these filenames for the current placeholders:
- certificate-01.jpg
- certificate-02.jpg
- certificate-03.jpg

Then edit the `certifications` section in `script.js` if you want different names, titles, organizations, or years.

Supported image formats include JPG, PNG, and WebP. If you use a different filename or extension, update the `image` value in `script.js` accordingly.
